# CPR 心肺復甦術

### 15.1 CPR 適用時機

- 戰術環境暖區：**不處理**創傷引起的 OHCA
- 先執行**雙側針刺減壓**，排除張力性氣胸
- 疏散期間（載具上）可考慮 CPR
- **以下非創傷原因才考慮 CPR**：低體溫 / 溺水 / 電擊

> CPR 過程中的通氣（BVM）操作原則、頻率與潮氣量控制，詳見 [06 章 BVM 正壓呼吸](/chapters/06-respiration#_6-1-bvm-正壓呼吸)
