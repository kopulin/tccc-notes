# CCP 開設與撤離

### 6.1 選址原則

- CCP ≠ 冷區，極高機率在暖區
- 需考量：安全性、掩蔽性、隱蔽性（大部分選家屋）
- 良好通訊條件
- 需有**備用 CCP** 與撤離/轉移計畫
- 明確規劃撤離方式（徒步、地面或空中載具）與友軍接近路線（日夜間標記與識別）

### 6.3 人員運作

- 高階醫療人員（CLS/CMC）在中央調度指揮，不長時間關注單一傷患
- 依醫事人員等級，高級人員負責調度，以此類推
- 分配綠卡/黃卡協助任務，讓他們有事可做
- 傷口必須被標記（留下線頭、在傷患身上做記號）
- 使用 DD1380 紀錄；以 MIST 格式與後方聯繫傷患數量與傷情

---

### 6.5 撤離

- 撤離前：再次確認接應方接近方向、載具種類、時間、識別方式
- 正常狀況：**紅 → 黃 → 綠**
- 大量傷患/危急狀況：可反向 **綠 → 黃 → 紅**
- 黑卡緊急狀況下僅帶走身份證明
- 抵達時依 DD1380 卡交接，明確指出傷情對應欄位；大型載具或直升機時，用手指示意
