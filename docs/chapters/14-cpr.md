# CPR 心肺復甦術

### 2.3 CPR 適用時機

- 戰術環境暖區：**不處理**創傷引起的 OHCA
- 先執行**雙側針刺減壓**，排除張力性氣胸
- 疏散期間（載具上）可考慮 CPR
- **以下非創傷原因才考慮 CPR**：低體溫 / 溺水 / 電擊
