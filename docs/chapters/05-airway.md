# A — 呼吸道

**原則**
- 即將發生氣道阻塞或心血管衰竭 → 立刻執行
- 有意識傷患：坐姿前傾，避免血液等回流
- 無意識傷患：壓額抬下巴，打開呼吸道後，置入NPA + 復甦姿勢
- 若持續性阻塞，給予上聲門呼吸道 SGA 或氣管插管 (Endo) (但傷患意識清楚的話，耐受性不好)
- 2026 T3C 指引更新：若 NAP 無法改善，建議直接環甲膜切開術(CRIC)

---

### 4.1 鼻咽管（NPA, Nasopharyngeal Airway）

**適應症**：意識不清，呼吸有鼾音（肌肉鬆弛導致舌根後置壓迫氣道）

**操作**
- 通常由右側鼻孔置入（較大）
- 垂直安置後用透氣膠帶固定

**優點**：傷患意識恢復後耐受性佳；可姿勢變換或戴防毒面具

**禁忌症**
- 顱底骨折（在戰術環境下，考量危急優先度可忽略）
- 顏面開放性創傷：鼻部結構缺損或破壞，無法置入
- 顏面燒燙傷合併鼻孔煙灰（碳粒）沉積：高度提示吸入性嗆傷，鼻腔與呼吸道極可能因水腫而快速腫脹

---

### 4.2 口咽管（OPA, Oropharyngeal Airway）

**適應症**：呼吸道內有液體（水、血液）— 先抽吸，再置入

**條件（兩者同時滿足）**
- 完全無意識
- 無嘔吐反應

> **TCCC 備註**：TCCC 場合幾乎不用——有嘔吐反射風險，且傷患意識變化時更難管理。

---

### 4.3 聲門上呼吸道裝置（SGAs）

> **[draft]** TCCC 最新指引已將 SGA 從 TFC 流程中正式移除。若 NPA/姿勢調整無效，建議直接 CRIC，而非嘗試 SGA。EMS / TACEVAC 階段仍為重要工具，操作細節待補充。

**TCCC 移除 SGA 的原因**
- 若傷患可耐受 SGA 的深層昏迷狀態，通常代表嚴重休克或 TBI
- SGA 對反流/誤吸保護有限，無法解決氣道解剖扭曲
- TFC 狀態下不推薦

**使用時機（EMS/TACEVAC 階段）**
- 深層昏迷且無嘔吐反射（GCS < 8）
- 無法執行氣管插管 (ETI) 的替代方案

**禁忌症（RODS）**

#### LMA

**事前準備**
- 置入前先充氣檢查是否洩漏，再**完全抽空**；確保氣囊平整、無皺褶
- 潤滑：僅潤滑**背面**（與咽後壁接觸面），勿潤滑正面通氣孔，避免潤滑劑進入通氣孔造成嗆咳

1. 傷患採「嗅物姿勢（Sniffing position）」
2. 像握筆一樣握住連接處
3. LMA 後端壓向硬顎(Hard Palate)，順口腔與咽部弧度向下滑，直到感受到**明顯阻力**
4. 置入過程中，確保舌頭不被捲入

**確認**
- 依型號充氣 → 觀察 LMA 向外彈出約 1–2 cm（在聲門上方自我定位）
- 觀察胸部起伏；聽診雙側肺部與胃部，氣灌入胃部會有異音；監測 EtCO2

**特點**
- 無需充氣氣囊，低壓環境較不受影響
- 成人通常用 Size 4（依**理想體重**，非實際體重）
- 潤滑：僅潤滑背面

**操作**
1. 雙手抬高下顎並張開口腔
2. 左手維持開口， iGEL 尖端朝向頭側方向置入
3. 將氣囊背側沿著門牙後方，順著硬顎與咽喉後壁的弧度壓著推入，氣囊部分全部進入後，頭部後仰，向前推動直到頂住食道入口處
4. 尖端抵達食道入口，感覺到有彈性的反彈感 = 到位
5. 接呼吸迴路，觀察胸廓起伏，並執行五點聽診法確認通氣
6. 膠帶固定：從一側下顎角，經過上顎繞過管子，貼至對側下顎角，將力量往背側與尾側施壓
7. 呼吸迴路盡可能往頭側方向垂放，不易脫落

**Trouble Shooting**
- 置入遇阻力 → 通常是舌頭被推下；稍微退出並加強抬高下顎後重新置入
- 置入時多次遇到阻力，每次都稍微退回一點，加強抬高下顎動作

### 4.6 兒科呼吸道

- 優先考慮 NPA + 復甦姿勢
- 除非懷疑頸椎/脊髓損傷，否則不要仰臥（仰臥因頸椎彎曲導致氣道阻塞）
- 上背墊高 3–5 cm
- 給予 BVM 等效於插管
