# R — 呼吸狀態

**檢查程序**
1. 移除裝備、剪開衣物，完整暴露傷患軀幹
2. 目視檢查軀幹是否有外傷、瘀傷、不正常狀態
3. 雙手抓爬每一部分皮膚，日夜間皆適用；光線充足時另以雙手撐開皮膚，避免細小破片傷口因皮膚皺褶而遺漏
4. 將傷患翻身（健側在下），檢查背部傷口：施救者可站於傷患髖部，以弓箭步前腳跨過傷患固定姿勢，再以雙手檢查背部
5. 翻身同時從頸部開始，依序以手觸摸每段脊椎，確認有無不正常突出、錯位

### 4.7 連枷胸（Flail Chest）

<figure>
  <img src="/images/flail_chest.png" alt="連枷胸圖" />
  <figcaption>連枷胸的剖面示意圖</figcaption>
</figure>

**受傷機轉**
- 高能量鈍挫傷（車禍、爆炸、高處墜落）
- 相鄰多根肋骨骨折，且單根有多段骨折，導致胸腔失去支撐
- 可能造成肺挫傷、出血與水腫，影響氧氣交換功能
- **可能發展為張力性氣胸，需密切觀察**

**辨識**
- 反式呼吸：吸氣胸腔內凹，吐氣胸腔外擴
- 胸腔疼痛導致淺快呼吸、低血氧、累積過多 CO₂ 
- 骨擦音、皮下氣腫（觸感如泡泡紙）

**處置**
- BVM 給氧（提供正壓支撐胸腔）
- 無脊椎受傷前提：適度向傷側側躺，壓迫傷側以限制浮動
- **不要**使用彈繃包覆加壓，效用不高且非常痛

### 4.8 開放型氣胸（Open Pneumothorax）


**受傷機轉**
- 開放性傷口大於氣管管徑3/4，空氣會從傷口進入胸腔(阻力最小)
- 吸氣時空氣透過傷口進入肋膜腔 → 負壓消失 → 患側肺泡塌陷、氧合障礙
- 縱膈擺動（Mediastinal Flutter）：患側壓力大，推擠健康側，影響氣體交換與心臟輸出
- 每呼吸一次，氣體會在左右兩側肺部來回流動，傷患一直吸入自己的高二氧化碳、低氧廢氣
- 來回擺動時，壓迫到大靜脈與心臟，導致心臟血流輸出降低
- 極高可能發展成張力性氣胸

**臨床症狀**
- 氣體交換失敗/效率不佳，導致廢氣累積，引發高碳酸血症、低氧血症、導致進行性發紺
- 縱隔擺盪，可能導致連接心臟的上下大靜脈 (SVC/IVC) 發生扭曲折疊，降低心臟靜脈回流量暴跌，導致梗阻性休克 (Obstructive shock)
- 縱隔擺盪可能導致周遭迷走神經被強烈刺激，引發反射性心律不整、甚至導致 OHCA

  <img src="/images/tension-pneumothorax.png" alt="縱隔擺盪" />
  <figcaption>開放性氣胸示意圖</figcaption>
</figure>

**處置**
- 使用有洩氣閥的胸封（Vented Chest Seal）
- 即造胸封：貼三留一（預留小縫隙）
- 在**吐氣時**貼上
- 密切監控是否轉變為張力型氣胸 (臨床症狀與生命徵象)

**其他**
- 若因迷走神經導致的心跳驟停等，先停止縱隔擺動
- 封閉傷口、改變傷患姿態 (半坐臥姿、或朝傷側側躺)，利用重力減少縱隔擺動減輕拉扯
- 其他進階治療都是藥物，日後再補

### 4.9 張力型氣胸（Tension Pneumothorax）

> ⚠️ **張力型氣胸會導致 OHCA。** TCCC/大傷環境下，OHCA 傷患建議進行雙側針刺減壓，排除此可能性。

#### 受傷機轉
- 胸腔傷口隨呼吸或姿態變動，受損的組織可能發生位移，形成一個單向氣閥(Flap Valve)
- 單向氣閥使得吐氣運動時，傷側累積的氣體無法被排出，持續累積
- 空氣在胸腔傷側處，胸腔壓力增加並壓迫心臟與大靜脈 → 心臟血流輸出降低

#### 處置

**Step 1：胸封 Burp**
- 強烈建議使用單向排氣閥的胸封
- 撕開胸封，「burp」排出積聚氣體，若狀況改善則表示是胸封失效導致的

**Step 2：針刺減壓（NDC, Needle Decompression）**

依照 TCCC 準則，建議執行**雙側**針刺減壓

**操作要點**
- 針頭斜面（缺口）朝向足側，垂直進針

**減壓失敗時**
- 除非插錯側（例如傷側在左卻誤插右側），否則**不拔出**留置的針具
- 針具本身也是一個傷口：拔出後務必以胸封密合，避免後送階段遺漏未被發現的傷口

**Step 3：手指胸式造口術（Finger Thoracostomy）**
- 位置同 NDC 首選（第 4–5 肋間，腋前線）
- 刀片水平切開約 3–4 cm（在肋骨**上方**邊緣）
- 大型止血鉗穿透肋間肌與壁層肋膜
- 手指伸入，感覺肺組織或氣流/血流噴出
- 手指轉一圈確認無沾黏、通道暢通
- 某些戰術情境下保持傷口開放、維持通氣（Simple Thoracostomy）
