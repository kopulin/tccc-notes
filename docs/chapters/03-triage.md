#### 30-2-Can Do 流程
<figure>
  <img src="/images/30_2_cando.png" alt="START 檢傷分類" />
  <figcaption>EMS 檢傷分類流程</figcaption>
</figure>

1. **可以行走** → 綠卡
2. **呼吸評估**：無呼吸 → 暢通呼吸道
   - 有呼吸 → 紅卡
   - 無呼吸 → 黑卡
3. **呼吸速率 > 30/min** → 紅卡
4. **CRT > 2s，或橈動脈微弱以下** → 紅卡
5. **意識檢查**
   - 有意識 → 黃卡
   - 無意識 → 紅卡

---

#### 在戰場環境、軍事行動下的檢傷分類
1. **是否大出血** → 是，紅卡
2. **是否可自行移動** → 否，黃卡
3. 其餘皆為綠卡

#### 二次分類

- 是否可以行走
- 疏散通道是否安全
