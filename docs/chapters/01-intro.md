# 概論與原則

### 1.1 核心理念

- 必須保持警戒，醫療處置受到限制，且會有復合性傷情
- 極端環境、有限設備下運作
- **沒有標準解答**：「時間、地點、傷患、處置」四要素都是變數
  - 好的醫療可能是不對的戰術；不對的戰術會導致所有人死亡或任務失敗
  - 在錯誤的時間進行正確的治療，也可能導致更多傷亡
- 要往大量傷患情境設想，保持警戒
